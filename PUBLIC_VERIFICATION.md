# Mac 0.4.11 public verification

The actual public Mac game, source and checksum downloads match the final local SHA-256 hashes and sizes. The repository's latest release resolves to0.4.11, so the game's updater has a stable public Mac release and SHA-256 destination; this download/hash check alone does not establish installation/restart. The signed app's main executable retains mode0755. Current native Intel/Apple Silicon reports and inspected screenshots are described in VALIDATION.md. Current0.4.11 live internet play, human gameplay and other macOS versions remain untested. This is local ad-hoc signing, not Apple Developer ID/notarization.

After publication, the actual in-game updater passed all 5 public-download/install/restart checks on Intel macOS 15 (run 38622429539). Its downloaded game SHA-256 matched the published archive, the native helper recorded `installed-and-restarted`, and the new child acknowledged its first live frame with matching process/token receipts. The caller app and outside-file sentinel remained unchanged. Both Intel and Apple Silicon macOS 15 also passed all 27 local native archive/install/restart/rollback checks (run 38619613930).

Apple Silicon actual-public validation is incomplete. One macOS 15 caller timed out after 300 seconds without a native installer handoff (run 38624447090); its early child failure status was not exported by that runner, so its precise cause remains unproven. A single diagnostic on supported ARM macOS 26 (run 38626373317) confirmed the hosted anonymous GitHub API route was exhausted: HTTP 403, remaining quota 0, and an explicit API-rate-limit response. That diagnostic stopped before launching the game. No further blind retries were made, and no workflow token was passed into the production game. This is not an Apple Silicon actual-public-update pass.

Raw public receipts, failed reports and quota response are in release-evidence/0.4.11; the machine-readable scope is release-evidence/mac-public-updater-0411.json. Published game/source archives and frozen production source were not changed for these after-publication checks. Physical-Mac performance and live internet joining remain unverified.
